# CODEARIZONA

# Meridian AZ

Competition prototype: Arizona classroom remaining-need network + nonpartisan education-bill context.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo path (3 minutes)

1. Landing → **Open the weather lab**
2. See markers **8 / 20**
3. **Give 5** → watch **13 / 20**
4. Map → another campus
5. **HB 2316** → official bill text + Find your legislators
6. **Reset demo** (bottom right) before the next judge

## What is real vs demo

- **Demo:** teachers, requests, donors, quantities, wishlists
- **Real:** bill text/status sourced from azleg.gov, chaptered laws, official fact sheets, Governor veto reporting
- School names/pins are public campus locations. Those schools are **not** partners.
